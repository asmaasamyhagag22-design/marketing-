# سجل تنفيذ Campaign Planner

نقطة البداية `c6095a610a8f5703c5e00e734ec4f621cdb7acc6` على `codex/adzy-campaign-integration`. سجل الـZIP ومعاينات المقاسين موجودان في الدليل الأب. worktree التنفيذ `codex/adzy-campaign-planner`. commit البروتوكول `7b16141` سبق تنفيذ المسار والتشغيل المباشر.

## معمارية القرار

- تبويب Campaign يقبل الرابط والهدف واللغة، ويستخدم `/planning-state` للحصول على النسخة المتوقعة و`/plan` لحفظ قرار البحث. يقبل حسابًا بلا براند، وينشئ سجل تعريف بسيطًا وبروفايل مربوطًا بالطلب داخل معاملة الحفظ. البحث العام لا يحتاج مفاتيح مزود.
- قرار البحث يفرّق بين شرح ميزة، تنزيل، وهدف تجاري. يختار صفحة بتطابق الرابط والموضوع. في التنزيل يطلب رابط إجراء من نفس الناشر ويقرأ عنوان الوجهة. سعر أو خصم أو إجراء تجاري يحتاج عقدًا صريحًا للشروط. يظل سبب الامتناع ظاهرًا ومعه سؤال محدد.
- يحفظ `Run.output` مسودة `DRAFT` ودليلها وقراراتها. حفظ مراجعة الـbrief ينسخ الدليل نفسه إلى Run جديدة ويشغّل compiler الحزمة. يمكن تعديل فرضية الجمهور والنبرة واختيار الاتجاه. النص الواقعي في هذا المسار محصور في الاقتباس أو تسمية قسم المصدر أو عبارة تأطير محكومة. الترجمة الإبداعية الحرة والتحقق الدلالي الشامل خارج التغطية.
- بقي JSON import لمسار الحزم السابقة. التصدير يعيد فحص ملكية البراند والنسخة والموافقة. ملفات PNG تظل مرتبطة ببصمة نفس النسخة.
- الاقتباسات من الناشر فقط في الحالات المؤتمتة. المقارنة مع المنافس اختيار استراتيجي للمراجع، ولا يقدّم المسار حكم تفوق. عناوين المنتجات قد تبقى بلغة المصدر على البوستر العربي. حدود اللغة المتاحة ar/en، وقواعد البحث المعجمية لا تترجم موضوع الهدف بين اللغات. السوق والفرع والسعر والصلاحية حقول غير مثبتة في المخرجات العامة. يحتفظ المسار بالسياق، ويمتنع حين يطلب الهدف عرضًا تجاريًا.
- حارس URL القائم يفحص الوصول. سقف الخطة أربع قراءات و12 ثانية بين المحاولات، و2MB للصفحة. إعادة الإرسال لنفس request ID تستعيد النسخة الحالية إن كانت هي نتيجة الطلب. طلب قديم بعد نسخة لاحقة يرجع 409. الطلبات المتزامنة قد تكرر القراءة العامة قبل الحفظ، ويقبل القفل نسخة واحدة.

## سجل النقد

- اختيار الدليل المبكر قدّم عنوان قسم قريب وجملة عامة تتشارك كلمات مع الهدف. فحص Firefox وRijksmuseum كشف أن التطابق مع الصفحة وحده لا يكفي. رُجّحت تسمية القسم الأقرب، وأعيدت موازنة الكلمات الشائعة وأسماء الميزات داخل النص، واستُبعدت مقدمات من نوع “Just …” من الاقتباس المحوري. ترتيب المصادر معجمي، وحكم الملاءمة يبقى جزءًا من المراجعة.
- في التشغيل الأول للمتصفح تم تحميل بيانات براند LEGO أثناء ملء نموذج Rijksmuseum. حُفظت نتيجة الامتناع التاريخية كتجربة فشلت عند حد الإدخال. فحص الرحلة الحالي ينتظر تحميل تبويب Campaign ويتحقق من JSON المرسل قبل احتساب الحالة.
- أظهرت اختبارات HTTP الأولى أن استخدام نفس نطاق fixture في عدة اختبارات يتركه ملكًا للمستخدم السابق في PostgreSQL. جرى عزل نطاقات الاختبار. أضيف اختبار مستقل لتعارض نص المصدر، مع نسخة مجهزة للمراجعة مقابل إشعار صريح بانتهاء الميزة.
- طلب Qwen تجريبي على Firefox بلغ 150 ثانية وكتب JSON جزئيًا. احتوى عبارة سلامة أوسع من الاقتباس. هذه ملاحظة على النص الجزئي. لا تدخل المحاولة التشخيصية في مقام المقارنة الأساسي.
