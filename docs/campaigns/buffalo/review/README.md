هدف Five Guys سمّى Bacon Burger. نفس بصمة HTML وعدد الزيارات (1) في القياسين. قبل الإصلاح كان الوصف والاسم لصنف Little Bacon Burger. بعده ظهر الاسم Bacon Burger واقتباسه الكامل في الدليل. الرسالة المرئية تستخدم اسم القسم لأن طول الجملة يتجاوز حد رسالة البوستر.

في Nando’s تطابق اسم Grilled Chicken Wrap مع الهدف قبل وبعد على اللقطة المختصرة والصفحة الكاملة. على المختصرة كان الاقتباس جملة عن صدر الدجاج، وعلى الكاملة جملة عن اللفافة ومكوناتها. تغيير تكرار الكلمات نتيجة التنقيح أثّر على اختيار الجملة، واسم الصنف ظل ثابتًا. هذه حالة توافق بعد تثبيت قاعدة الاختيار، وحالة Nando’s الحية سجلت حاجز جلب مستقل.
