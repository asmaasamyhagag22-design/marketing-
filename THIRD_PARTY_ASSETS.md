# Public asset disposition

This candidate retains application source and project-created demo material, without adding a repository-wide license grant. Public visibility does not automatically make source open source. Existing ownership and terms are unchanged.

| Material | Decision and basis |
|---|---|
| ADZY code-authored SVGs (`logo-mark.svg`, `logo.svg`, `adzy-spark.svg`) and text wordmark | Retained as original project source/branding. Simple SVG geometry/text is visible in source. A logo is not automatically prohibited merely because it is a logo. No external brand authorization is claimed. |
| Fictional Studio Fixture raster, app screenshots and synthetic showcase copies | Retained: generated by the project's local compositor/app/test fixtures with explicitly fake external responses. Provenance is in `docs/results/provenance.json`; screenshots do not certify live model quality. |
| Existing `frontend/assets/logo.png` | Excluded from this candidate as an optional opaque raster with no separate provenance record; its two UI references now use the existing project-authored SVG mark. Original preserved in the owner's checkout. |
| Firefox SVG/logo/artwork, embedded/data-URI preview files, original rejected PNGs and manual preview assets | Excluded. Official asset URLs and attribution establish origin, not an accompanying redistribution grant. No blanket claim that Firefox marks are forbidden. No change to historical rejection/acceptance results. |
| Historical branded Nahdi/Volume concept PNGs | Excluded as optional promotional media without a supplied redistribution basis; not silently recast as accepted client work. Original files remain local. |
| Previous customer-derived showcase | Not copied. Public showcase now consists solely of the project's three labeled synthetic app/fixture examples. |
| Noto | The available full SIL OFL1.1 notice is preserved in `docs/licenses/Noto-OFL.txt`. The four managed Noto Sans / Noto Sans Arabic regular and bold TTFs in `poster/fonts/` are redistributed under that notice for offline canonical composition. These are installed Debian Noto font binaries, not portfolio media. Optional Google Fonts references remain separate dependencies for legacy rendering. |
| Existing test fixtures, including required calibration imagery | Retained with the existing tests from remote main, as required regression inputs rather than newly promoted campaign/portfolio examples. This preparation does not modify or run the legacy media subsystem or claim a new provider-rights grant. |

No authorization objects, usage/run snapshots, customer databases/media, environment secrets, private workflow state or test scratch are included. Text-only regression fixtures can cite public brand statements; they do not embed the excluded artwork or assert live acceptance. Historical case helpers are retained for authorization regression compatibility but require their own inputs; the fictional poster demo uses its own documented workflow.
